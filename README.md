# guia07-mi-proyecto-web

Proyecto web básico (HTML, CSS y JavaScript) usado para practicar control de versiones con Git y GitHub.

## Funcionalidades
- Saludo personalizado según la hora del día.
- Validación del nombre (solo letras y espacios).
- Formulario de contacto con validación del formato del correo.
- Mensajes dinámicos de éxito y error, y uso de la tecla Enter.

## Evolución del proyecto
| Versión | Cambio |
|---|---|
| 1 | Estructura inicial (HTML, CSS y JS de la guía) |
| — | Actividad 02: publicación en GitHub y rama `feature-formulario` |
| 2 | Rediseño de estilos |
| 3 | Funcionalidad: saludo por hora, tecla Enter, limpieza de campos |
| 4 | Mejora: validación con expresiones regulares y mensajes dinámicos |

## Cómo ejecutarlo
Abrir `index.html` en el navegador.
